1. Copy this folder into C:\xampp\htdocs\ and start Apache + MySQL in XAMPP.
2. Open http://localhost/phpmyadmin -> Import -> database/ticket_booking.sql
3. Open http://localhost/ticket-booking-website/index.html
4. Optional: add posters to images/ as movie1.jpg, movie2.jpg, movie3.jpg (a text poster shows until then).
DB login is in php/db.php (XAMPP default: root, no password).
